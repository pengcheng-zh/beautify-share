# 贤书·置换

> 人间烟火，书市清灵。
> 一个雅致的旧书置换与书市分享社区（uni-app / Vue3 / Pinia）。

## 功能

- **启动页**：竖排逐字呈现「人间烟火，书市清灵。」，自动入市
- **书斋**：书友发布的信息流（文字 + 最多 9 图 + 语音 + 定位），朋友圈式布局，支持点赞 / 评论 / 收藏 / 分享
- **发布**：悬浮「＋」进入，可写文字、选图、按住录音、添加书市定位，提交后进入审核
- **我的**：用户信息、发布记录（待审核 / 已通过 / 未通过）、我的点赞 / 收藏 / 分享
- **掌柜台**：管理员审核内容与评论，通过 / 驳回 / 撤销处理

## 技术栈

- uni-app（Vue 3）+ Pinia 状态管理
- 数据持久化：本地 Storage（`xs_*` 键），首次启动自动注入 mock 书市数据
- 主题：新中式书卷风（宣纸底、墨色、朱砂、石青）

## 目录结构

```
pages/
  splash/            启动页
  tabBar/books/      书斋（信息流）
  tabBar/mine/       我的
  publish/           发布书帖
  detail/            书帖详情与评论
  mine/              我的发布 / 点赞 / 收藏 / 分享
  admin/             审核管理
components/
  content-card/      朋友圈样式内容卡片
store/
  user.js            当前用户
  content.js         内容、评论、审核、互动
common/
  format.js          时间与状态格式化
static/
  tab/               tabBar 图标
  mock/              mock 书市图片
```

## 运行

使用 HBuilderX 打开项目根目录，运行到 H5 / 微信小程序 / App 即可。

- 默认登录用户为掌柜（管理员），可在「我的 → 掌柜台」体验审核流程
- 演示数据含一条待审核内容与一条待审核评论
